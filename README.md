## 🎯 Interview Questions Practiced

### Q1. What is Java?

Java is a high-level, object-oriented programming language designed to be platform independent through the Java Virtual Machine (JVM).

### Q2. What is JVM?

JVM stands for Java Virtual Machine. It executes Java bytecode and enables Java programs to run on different platforms.

### Q3. What is JDK?

JDK stands for Java Development Kit. It provides tools required to develop, compile, debug, and run Java applications.

### Q4. What is JRE?

JRE stands for Java Runtime Environment. It provides the environment required to run Java applications.

### Q5. What is the difference between JDK, JRE and JVM?

```text
JDK
 ↓
JRE
 ↓
JVM
```

* JDK → Used for Java development
* JRE → Used to run Java applications
* JVM → Executes Java bytecode

### Q6. Why is Java platform independent?

Java source code is compiled into bytecode. The bytecode can run on any operating system that has a compatible JVM.

## 🔍 Key Learning

One important concept I understood today is the Java execution process:

```text
Java Source Code
       ↓
   Java Compiler
       ↓
   Bytecode (.class)
       ↓
       JVM
       ↓
Machine Code
       ↓
    Output
```

This explains how Java achieves platform independence.
